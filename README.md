# Interactive Fiction Game

This project is an interactive fiction game with a Vue.js frontend and a Python backend.

## Dependencies

### Backend (Python)

The backend is built using FastAPI. The dependencies are managed with Poetry and are listed in `backend/pyproject.toml`.

- `fastapi`
- `uvicorn`
- `python-dotenv`
- `pyautogen`

### Frontend (JavaScript)

The frontend is a Vue.js application. The dependencies are listed in `vue-project/package.json`.

- `vue`
- `pixi.js`
- `pixi-live2d-display`
- `vite` (as a development dependency)
